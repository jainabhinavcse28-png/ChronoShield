📐 How Cross-Database Polyglot JOIN Works:

Unlike single-model relational databases that perform heavy multi-table SQL JOIN operations, ChronoShield separates write-heavy log storage (MongoDB) from relationship path-finding (Neo4j). When an analyst requests deep forensic investigation for an asset, the application performs an in-memory Cross-Database Polyglot Hash Join using the common foreign identifier (host_id or username), unifying the graph risk metrics with raw telemetry payloads in sub-millisecond latency.

🔌 Connect / Join Live External Databases

Configure live MongoDB Atlas & Neo4j AuraDB connections

ChronoShield automatically runs with an internal high-performance fallback engine so it works anywhere. To join a live external or local database cluster, update your environment variables or config.py:

# MongoDB Connection (Local or MongoDB Atlas Cloud) MONGO_URI="mongodb://localhost:27017/" # or "mongodb+srv://user:pass@cluster.mongodb.net/" MONGO_DB_NAME="cyber_attack_db" # Neo4j Connection (Local or Neo4j AuraDB Cloud) NEO4J_URI="bolt://localhost:7687" # or "neo4j+s://xxxxxx.databases.neo4j.io" NEO4J_USER="neo4j" NEO4J_PASSWORD="your_password"
